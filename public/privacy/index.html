Privacy Policy

The Padel Archive streaming tool · operated by Danske Padel Klip, publisher of PadelTicker · effective 11 September 2026

This policy covers the streaming tool only. It does not describe the PadelTicker live-score website.

What the tool is

The Padel Archive streaming tool is an internal application used only by the owner of the YouTube channels The Padel Archive and Danske Padel Klip. It schedules and runs live streams of padel matches on those channels and keeps each stream's title and description up to date. It is not offered to the public, and no one other than the channel owner signs in to it.

Google user data the tool accesses

When the channel owner signs in with Google, the tool requests access to the YouTube Data API with these scopes:

  • youtube.readonly - to list the channel's own live broadcasts and live streams;
  • youtube - to create live broadcasts on the channel and update their titles, descriptions and visibility;
  • youtube.force-ssl - to post attribution comments on the channel's own videos where a footage provider requires it.

The tool only reads and changes data belonging to the signed-in owner's own channel. It does not access any other user's data, subscriber lists, watch history or private messages.

How the data is used

Data obtained through the YouTube Data API is used solely to create and manage broadcasts, titles, descriptions and comments on the owner's own channel. It is not used for advertising, profiling or analytics, and it is not sold, rented or shared with anyone.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The only data stored is the OAuth access and refresh token issued by Google, kept in a file on the channel owner's own computers. It is never uploaded to a server, database or third-party service. Broadcast titles and descriptions are sent only to YouTube.

Retention and deletion

The token is kept for as long as the owner uses the tool. Access can be revoked at any time at myaccount.google.com/permissions; deleting the token file removes all stored data. Content on YouTube is governed by YouTube's own policies.
