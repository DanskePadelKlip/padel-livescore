# PadelTicker robots policy
#
# Search and answer engines that send traffic back are welcome everywhere.
# Training-only crawlers, which take the aggregated federation data and return
# nothing, are disallowed. Note Google-Extended and Applebot-Extended control
# AI training ONLY - they do not affect Googlebot or Applebot search indexing.
#
# Deliberately still allowed: OAI-SearchBot and PerplexityBot. Those power
# answer engines that cite and link, so they are an acquisition channel.

User-agent: *
Allow: /
# The JSON API is for the app, not for indexing. Every page's <head> is
# server-rendered, so a crawler loses nothing by skipping these - and a crawl of
# the 3,982 /player/ URLs in the sitemap, each firing /api/player, once spent the
# whole daily D1 read budget and took the live site's player pages down with it.
Disallow: /api/
