The Padel Archive streaming tool

An internal application from Danske Padel Klip, the publisher of PadelTicker, used to broadcast padel matches live on the YouTube channels The Padel Archive and Danske Padel Klip.

What it does

  • Creates and schedules live broadcasts on the owner's own YouTube channels.
  • Keeps each broadcast's title and description current - the tournament's order of play, and the pair actually on court.
  • Posts attribution comments on the channel's own videos where a footage provider requires it.

Who uses it

Only the owner of those channels signs in with Google, and the tool only reads and changes that owner's own channel. It is not offered to the public.
